# Chromabot-Autonomous-Colour-Sorting-Robot (VEX)
The Chromabot performs an automated colour-sorting task, whether after a drawing session or when the workspace becomes cluttered during one. It detects the hue of each pencil, determines which colour’s sorting box the pencil belongs to, moves to the correct location along a linear path, and deposits the pencil. It repeats this process for all loaded pencils without further user intervention. Timing information is also recorded so that the overall calibration and sorting performance can be evaluated.
